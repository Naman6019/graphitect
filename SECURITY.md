# Security policy

## Supported versions

Security fixes are made on the latest `0.2.x` release on `main`.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability.

Use GitHub's private vulnerability-reporting option from this repository's
**Security** tab. If it is unavailable, contact the repository owner through
their GitHub profile and include:

- a short description and affected version or commit;
- minimal reproduction steps or proof of concept;
- impact and any suggested mitigation.

Please do not include API keys, access tokens, or private repository contents
in a report. Reports are assessed before public disclosure; no response-time
service-level agreement is promised for this volunteer-maintained project.

## Scope

Reports are welcome for Graphitect's CLI, bundled Graphify and Archify code,
packaging, generated reports, and documented skill workflows. Third-party
services and a target codebase's own vulnerabilities are out of scope unless
Graphitect itself causes the exposure.
